# MND Homes - Visual Website Content & Asset Hub

A standalone, production-ready static content and asset hub for **MND Homes (Mom & Dad Welfare)**.
Built to preview original website data, structures, and assets in their exact sequence, with one-click copy functionality and direct image downloads.

## 🚀 Deployment

This project is structured for zero-configuration instant deployment on [Vercel](https://vercel.com):
- `index.html`: Complete responsive web app with interactive tabs, visual preview, copy board, and live search.
- `images/`: All 36 production images and icons extracted from original uploads.
- `vercel.json`: Clean URL routing and immutable asset cache headers.

## 📋 Features Included
- **Home Page (9 Sequential Sections):** Hero Banner, Charity Services, About MND Homes (500 Children Phase 1), Donation Causes, Call to Action, Success Stories, Impact Stats, Leadership Testimonials, and FAQs.
- **Dedicated Tabs:** About Us, Team & Leadership, Campaigns & Causes, Charity Services, Photo Gallery, Testimonials, FAQs, Contact Us, and Products Catalog.
- **Developer Tools:** One-click copy for every headline, paragraph, quote, phone, email, and asset path.
- **Dual View:** Toggle between "Visual Website Preview" and "Data Copy Board".
